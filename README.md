# Безумное UNO

Страница проекта: **<https://danylodev.com/projects/crazy-uno/>** · автор: [Danylo Syloats](https://danylodev.com/)

3D-UNO для компании: онлайн-комнаты по коду или ссылке, либо игра на одном устройстве.
Режимы «Классика» (официальные правила), No Mercy, «Вечеринка» и «Полный хаос»: стопка штрафов, 7 и 0, бомбы, фанты, наказание проигравшему и 13 случайных «безумных событий».
Боты трёх уровней: лёгкие, обычные и хитрые (перед каждым ходом мысленно доигрывают партию сотню раз).

## Как это устроено

```
src/
  main.tsx        точка входа
  app/            корень приложения: какой экран открыт, локальная игра, вход в комнату
    hooks/          проверка сервера, онлайн-игра
    storage/        сохранение настроек и незаконченной партии на устройстве
  game/           правила игры — чистый TypeScript без UI, работает и в браузере, и на сервере
    engine/         движок: Game.ts (ходы, вызовы, таймеры, конец раунда),
                    cardEffects.ts (что делает каждая карта), lookahead.ts (как думает хитрый бот)
    rules.ts        можно ли сходить картой, порядок ходов, «поймать без UNO»
    bot.ts          как решают боты и автопилот
    events.ts       случайные «безумные события»
    deck.ts, content.ts, stats.ts, reactions.ts, teams.ts, avatars.ts
  net/            протокол (общий с сервером), WebSocket-клиент и онлайн-зеркало игры
  three/          3D-стол (react-three-fiber)
    scene/          сцена: камера, стол, стрелки, маркер хода, колода
    layout/         раскладка: где лежит каждая карта (рука, веера соперников, колода, сброс)
    cards/          3D-карта, её текстуры и перетаскивание
    players/        плашки соперников, подиум финала
    effects/        эффекты карт и событий, бомба, взрыв, конфетти, общие часы эффектов
    mascot/, van/   самолётик-маскот, бус за выбывшим
    themes/         пять тем стола
  ui/
    screens/        home/, lobby/, setup/, about/, howto/ — по папке на экран
    game/           всё поверх стола: hud/, модалки, баннеры, реакции, hooks/
    components/     общие компоненты (аватар, иконки, phone/ — подсказки для телефона)
    settings/       панели правил, стола и темы
    profile/        профиль, статистика, достижения
    backdrop/       живой фон меню в цвет выбранного стола
  styles/         tokens.css (цвета, шрифты), global.css, buttons.css, utilities.css
  lib/            мелкие утилиты: подписка для React, localStorage, debug.ts (отладка с ?debug)
  i18n/, audio/, art/   переводы, звуки, нарисованные аватары и иконки
server/
  server.ts       HTTP + WebSocket на одном порту
  static.ts       раздача собранной страницы (с превью для ссылок-приглашений)
  room/           Room.ts — комната: участники, раздача, реванш, таймеры; playerView.ts — что видит каждый игрок
  limits.ts       ограничения на один адрес
```

Стили лежат рядом с компонентом (`Lobby.tsx` + `Lobby.css`); общие цвета и шрифты — в `src/styles/tokens.css`.

Сервер — единственный источник правды: каждый игрок получает только свои карты, чужие приходят рубашкой вверх.

Надёжность:
- клиент сам переподключается (с нарастающей паузой) и возвращается на своё место по токену, даже после перезагрузки страницы;
- если игрок пропал (обрыв связи), его ходы через 12 секунд делает автопилот;
- кто не успел сходить (кончился таймер или 75 секунд бездействия), тянет карту и пропускает ход, как в официальном онлайн-UNO; если хост включил «Автопилот», вместо штрафа за него ходит бот;
- кто ушёл посреди партии, того заменяет бот; хост переходит следующему игроку;
- зашедший во время партии смотрит как зритель и играет со следующего раунда;
- пинги раз в 10–25 секунд вычищают мёртвые соединения, пустые комнаты удаляются через 5 минут.

## Команды

```bash
npm install
npm run dev      # сервер + клиент с горячей перезагрузкой: http://localhost:5173
npm test         # движок (сотни партий) + сервер (настоящие WebSocket-клиенты, переподключения, автопилот)
npm run lint     # ESLint: TypeScript и правила хуков React
npm run build    # клиент в dist/, сервер в dist-server/
npm start        # продакшен-сервер на $PORT (по умолчанию 8080)
```

## Выложить в интернет

Подробная пошаговая инструкция — в [DEPLOY.md](DEPLOY.md). Кратко:

Нужен хостинг, который держит постоянный Node-процесс с WebSocket (обычный статический хостинг не подойдёт).

- **Render**: подключи репозиторий, `render.yaml` уже готов (бесплатный план засыпает без посетителей, комнаты при этом сбрасываются).
- **Railway / Fly.io / любой VPS**: есть `Dockerfile`, порт берётся из `PORT`.
- **Быстро на вечер со своего ноутбука**: `npm run build && npm start`, затем
  `npx cloudflared tunnel --url http://localhost:8080` — получишь публичную https-ссылку, пока ноутбук включён.
